## 4. 공개 채점 정책

- 백엔드가 `WRITE_POLICY=public_demo`와 명시적 `PUBLIC_DEMO_ACKNOWLEDGED=true`로 익명 쓰기를 허용합니다. 방문자에게 별도 로그인이나 관리자 bearer token 입력을 요구하지 않습니다.
- 쓰기 요청은 프로세스 전체 60초 창으로 제한합니다. 기본값은 분당 60건이며 한도 초과는 `429 DEMO_RATE_LIMIT`입니다. 방문자별 인증 또는 분산된 트래픽 제한을 구현했다고 주장하지 않습니다.
- 프론트는 성공한 readiness의 `X-M18-Write-Policy`를 확인해 작성·삭제 UI를 활성화합니다. `FRONTEND_FORCE_READ_ONLY=true`는 공개 채점 UI를 강제로 읽기 전용으로 유지하는 설정입니다.
- 리뷰 등록은 실제 분석 뒤 결과를 함께 저장합니다. 클라이언트 제한 시간은 120초이며 쓰기 자동 재시도는 없습니다. 시간 초과가 발생하면 동일 입력 재제출 전에 저장 목록을 확인합니다.
- 리뷰 삭제는 해당 리뷰의 확인 체크박스, 영화 삭제는 해당 영화의 확인 체크박스를 사용합니다. 영화 삭제 시 관련 리뷰와 분석 결과가 DB cascade로 함께 삭제됩니다.

구체 API 정책·오류·헤더는 [API 계약 설명](API_CONTRACT.md)의 2026-10-19 보완 절을 따릅니다.

## 6. 검증된 최종 제출물과 인계

**로컬 제작·검수 상태는 `FINAL_PACKAGE_VERIFIED`입니다.** ZIP 내부 루트는 `미션18/미션18_2팀_이형기/`이며 소스, 채점 안내, 설계·ERD·출처, R2 PDF, 화면 원본, 실행 근거 및 체크섬을 포함한 **138개 파일**을 검증했습니다.
